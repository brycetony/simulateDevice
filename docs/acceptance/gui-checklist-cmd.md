## 清单

1. **删除确认框：取消静默 + 确认刷新**（CMD-08/F-13）：删除某命令 → 弹确认框 → 点「取消」：
   无任何弹窗、列表不变；再点「确定」→ 「删除成功」提示 + 列表刷新、该行消失。
2. **X / ESC 取消同样静默**（CMD-08 防回归注记）：确认框分别用右上角 X 与 ESC 关闭：无「删除失败」
   弹窗（观察点：distinguishCancelAndClose 恒 false——若未来出现 reject 'close' 行为，须重裁 CMD-08）。
3. **API 失败单点一弹**（F-13 / AUTH-05）：停后端后分别触发「列表加载 / 新增提交 / 删除确认」：
   每个操作**仅一个**错误弹窗（拦截器文案），无叠加双弹窗、无英文技术文案直达。
4. **占位符联动一符一行**（CMD-05/06 版本 B，D14/D15/D16）：新增命令，reqStream 依次输入——
   a) `[$a|1][$b|2]` → 参数区追加**两行**；b) 改为 `[$a|1] mid [$b|2]` → 仍两行（隔文本不并段）；
   c) 删掉 `[$b|2]` 文本 → b 行若仍全空则消失；在 b 行填过参数名称后再删文本 → b 行保留。
5. **表单校验双轨**（CMD-04 版本 A）：空表单直接提交 → 恰 4 条必填拦截（响应码流不在内）；
   参数行留空提交 → 参数行必填拦截；手动加参数行 → 参数类型下拉默认空（Q15 现状）。
6. **搜索重置第一页**（CMD-09）：翻到第 2 页后搜索关键字回车 → 回到第 1 页且结果过滤；
   清空搜索框（clear 按钮）→ 同样回第 1 页。
7. **reset 探针**（CMD-02）：编辑某命令（改动命令名称）→ 直接关对话框 → 再点新增：
   表单全空、params 空、URL 仍为本设备（deviceId 保留）、无上次编辑残留。
8. **编辑/新增分流**（CMD-07，网络面板）：编辑提交 → PUT /devices/command（载荷含 _id）；
   新增提交 → POST /devices/command（载荷**无 _id 键**，Q16）；入口：设备列表行「命令管理」按钮
   跳转 /devices/{id}/commands 且列表仅该设备命令（CMD-10）。
