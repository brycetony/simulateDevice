# GUI 验收清单：AUTH 域（T-004 §8 判据 1–6 的可重复执行版）

- 形态（T-005 裁决）：**文档 + 会话执行**——不引入 Playwright 等依赖；任何会话
  （含 web-gui-tester 类浏览器自动化）或人可按此清单逐条执行并记录。
- 前置：`npm run dev` 已启动；后端可达（`vite.config.ts` 代理目标）。
  后端不可达时：判据 5 可用「停后端」场景，判据 1–4/6 需后端在线，挂起留痕不阻塞。

## 记录规则

- 全过 → 回填对应任务卡 §8（勾选 + 日期）；任一不过 → 挂卡 §3 或直接开修复卡。
- 本清单即 AUTH 域回归基线：契约/拦截器/守卫相关变更后应复跑 1–6。
- 判据 7（D4 探针）已由 `docs/decisions/ADR-2026-11-09-d4-reset-probe.md` 关闭——一次性实验不构成缺陷，不纳入回归基线。
- 其他域复制此模式：判据从任务卡 §8 人工判据节生成，一行一操作一期望。
