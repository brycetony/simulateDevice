### 填表规则（agent 必须遵守）

- **类型**：`规则` = 业务上必须如此（有文档/ADR/故障复盘支撑）；`现状` = 代码当前恰好这么做。
  **现状 ≠ 规则**——现状可能本身就是 bug，不许把现状直接写成契约。
- **证据**：必须落到 `文件:行号` / commit / 测试名 / 工单号。写不出证据的，置信只能标 `推测`。
- **置信**：`有据` = 有代码外的事实支撑（文档、测试、决策记录）；`推测` = 仅凭"常见做法"。
  **所有 `推测` 条目默认按 OPEN 处理，人未裁决前不得作为实现依据。**
